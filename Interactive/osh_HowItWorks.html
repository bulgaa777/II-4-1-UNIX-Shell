5 · Нэг программыг ажиллуулах 2 арга5 · Two ways to run the same program

main() аргументуудаа шалгаад горимоо сонгоно. Веб UI болон тестүүд хоёр дахь горимыг ашигладаг тул энэ нь чухал.

main() checks its arguments and picks a mode. This matters because the web UI and the tests use the second mode.

Интерактив:Interactive: ./osh

Тасралтгүй давтана: osh> хэвлэнэ, мөр уншина, ажиллуулна, дахин эхэлнэ. exit эсвэл Ctrl+D дээр дуусна. previous хувьсагч сүүлийн командыг хадгалдаг тул !! ажилладаг.

Loops forever: print osh>, read a line, run it, repeat. It ends on exit or Ctrl+D. The previous variable keeps the last command, so !! works.

$ ./osh osh> echo hi hi osh> !! echo hi hi osh> exit

Нэг удаагийн:One-shot: ./osh -c "cmd"

Яг нэг команд ажиллуулаад гарна. server.py товч дарах бүрт шинэ osh процесс эхлүүлдэг, tests/test_shell.py ч мөн адил. Ажиллуулалт бүр цоо шинэ процесс тул previous үргэлж хоосон байна.

Runs exactly one command and quits. server.py starts a new osh process for every click, and tests/test_shell.py does the same. Because each run is a brand-new process, previous is always empty.

$ ./osh -c "echo hi | wc -c" 3 $ ./osh -c "!!" No commands in history.
Тэгвэл веб UI дээр !! яаж ажилладаг вэ? C кодыг огт ашигладаггүй. server.py HISTORY нэртэй өөрийн Python жагсаалттай. Та !! илгээхэд сервер osh-ийг дуудахаасаа өмнө сүүлийн командаар сольчихдог. C-ийн түүхийн код зөвхөн интерактив горимд болон "history replay" тестэд (жинхэнэ интерактив osh руу echo first / !! / exit оруулдаг) шалгагддаг. So how does !! work in the web UI? It doesn't use the C code at all. server.py keeps its own Python list called HISTORY. When you send !!, the server swaps in the last command before calling osh. The C history code only gets exercised in interactive mode and in the "history replay" test (which pipes echo first / !! / exit into a real interactive osh).
